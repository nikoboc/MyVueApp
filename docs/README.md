# TimeCard — 設計ドキュメント

**Vue 3 + TypeScript + Pinia** で構築する勤怠打刻アプリである。出勤・退勤・休憩開始・休憩終了を
記録し、過去の記録を修正できる。データはブラウザーの `localStorage` に保存し、サーバーは用いない。
学習を目的としたプロジェクトであり、成果物の完成よりも Vue のリアクティブかつ宣言的なモデルの習得を
主眼とする。

## 中心となる設計判断

**保存するのは打刻の列だけである。** 1 日の勤務時間や勤務状態はそこから導出し、保存しない。

打刻とその集計を両方保存すると、片方だけを修正したときに両者が食い違う。導出値を持たなければ
その不整合は起こりえない。過去の打刻を 1 件修正すれば、その日の実働時間も画面の表示も自動的に
追随する。詳細は [03 — 状態とデータ](./03-state-and-data.md) を参照。

## 前提となる考え方の転換

Java やサーブレットの経験がある場合、**手続き的**な発想になりやすい。すなわち「ユーザーが操作したら、
DOM を取得して書き換える」という考え方である。Vue は**宣言的**であり、**画面は状態から決まる**。
状態を変更すれば、DOM への反映は Vue が計算して行う。

本ドキュメントに記載した設計判断は、いずれもこのモデルに基づく。中心に位置するのがコンポーネントでは
なく状態（Pinia ストア）であるのも、同じ理由による。

## 確定事項

- **フレームワーク:** Vue 3、Composition API、`<script setup>`（現行の標準。Options API の解説は対象外）
- **言語:** TypeScript
- **ビルドツール:** Vite
- **状態管理:** Pinia
- **保存先:** ブラウザーの `localStorage`（API キー不要、サーバー不要）
