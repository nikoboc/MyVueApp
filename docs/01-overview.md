# 01 — 概要

## 目的

出退勤と休憩を記録するシングルページの勤怠打刻アプリを構築する。画面上のボタンで打刻し、その日の
実働時間が即座に表示される。過去の記録は一覧から確認でき、打刻の修正・追加・削除ができる。

## 中心となるユーザーストーリー

> 出勤時にボタンを押すと打刻され、勤務中であることと経過時間が画面に表示される。休憩の開始と終了、
> 退勤も同様に記録できる。打刻を忘れた場合や誤って押した場合は、後から一覧で修正できる。

## 機能

### MVP（最初に実装する範囲）

1. **打刻** — 出勤・休憩開始・休憩終了・退勤の 4 種類を記録する。
2. **勤務状態の表示** — 現在時刻、勤務状態（未出勤・勤務中・休憩中・退勤済み）、進行中の区間の経過時間。
3. **打刻の制御** — 現在の状態で打てない打刻は無効にする（休憩中に退勤を押せない、など）。
4. **日次の集計** — 実働時間と休憩時間を打刻から導出して表示する。
5. **過去の記録の一覧** — 日付ごとに打刻と集計を表示する。
6. **記録の修正** — 打刻の時刻と種別の変更、打刻漏れの追加、誤打刻の削除。
7. **操作の確認** — 打刻と削除は、実行前に確認ダイアログを表示する。
8. **打刻漏れの検出** — 対にならない打刻（退勤忘れなど）を警告として表示する。
9. **永続化** — `localStorage` に保存し、リロード後も記録が残る。
10. **スマートフォン対応** — 狭い画面でも操作でき、タップ領域は 44px 以上を確保する。
11. **オフライン動作** — ホーム画面へ追加でき、通信できない場所でも起動して打刻できる。

### ストレッチ（MVP の完了後）

- **月次の集計** — 月ごとの実働時間の合計と勤務日数。
- **勤務時間のグラフ** — 日ごとの実働時間の推移（Chart.js の再導入）。
- **CSV の書き出し** — 給与計算などへの受け渡し。
- **想定勤務時間との差分** — 所定労働時間に対する過不足の表示。
- **ダークモード** — テーマの切り替え。

## 対象範囲と対象外

**対象範囲:** フロントエンドのみ。クライアント側の状態管理、ブラウザーへの保存、打刻の集計。

**対象外とするもの（学習対象を限定するため）:**

- サーバーおよび API は用意しない。データはブラウザーの `localStorage` に保存する。公開も
  静的ファイルの配信のみで完結する（GitHub Pages）。
- 認証およびユーザーアカウントは扱わない。単一の利用者を前提とする。
- 端末間の同期は行わない。保存先はその端末のブラウザーに閉じるため、PC で打刻した記録は
  スマートフォンには現れない。
- 承認フローや申請機能は扱わない。記録した本人が直接修正する。

## 題材として適している理由

| 機能 | 習得対象となる Vue の概念 |
|---------|-------------------------------------|
| 打刻ボタン | イベント処理、ストアのアクションの起動 |
| 勤務状態による活性制御 | 算出プロパティ、状態からの導出 |
| 現在時刻と経過時間 | ライフサイクル（`onMounted`/`onUnmounted`）、タイマーのクリーンアップ、コンポーザブル |
| 記録の一覧 | リストレンダリング（`v-for`）、キー、コンポーネントの合成 |
| 修正フォーム | 双方向バインディング（`v-model`）、props と emit |
| 日次の集計 | 状態から導出する考え方、純粋関数への切り出し |
| `localStorage` への保存 | `watch` による副作用、外部データの検証 |
