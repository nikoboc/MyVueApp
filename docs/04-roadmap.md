# 04 — ロードマップ

各フェーズは、単体で動作する最小の単位であると同時に、1 つの Vue の概念に対応している。順序を飛ばさず、
各概念を理解したうえで次に進む。

## フェーズ 0 — 環境構築とリアクティビティの確認

**目標:** Pinia を組み込んだ Vite + Vue 3 + TypeScript のアプリケーションが動作すること。

- `npm create vite@latest` で Vue + TypeScript のテンプレートを生成する。
- `pinia` をインストールし、`main.ts` で組み込む。
- リアクティビティを確認するため、`App.vue` に一時的なカウンターを実装する（`ref`、ボタン、`computed`）。

**習得対象:** プロジェクト構成、`<script setup>`、`ref`、`computed`、`v-on`/`@click`、`{{ }}` による補間。
**完了条件:** `npm run dev` でカウンターが表示され、値が即座に更新される。

## フェーズ 1 — 型と集計処理（UI なし）

**目標:** Vue に依存しない、単体テスト可能な中核を構築すること。

- `types/attendance.ts` にドメインモデルを定義する。
- `services/time.ts` に日時の解析と整形を実装する。
- `services/attendance.ts` に `summarizeDay` と `allowedPunchTypes` を実装する。
- 打刻の配列を渡して結果を `console.log` し、想定どおりの実働時間になるか確認する。

**習得対象:** TypeScript のインターフェース、`as const` によるユニオン、判別可能なユニオン、純粋関数。
**完了条件:** 「9:00 出勤 / 12:00-12:45 休憩 / 18:00 退勤」に対して実働 8時間15分が算出できる。

## フェーズ 2 — 保存層と Pinia ストア

**目標:** 状態と保存を接続すること。

- `services/punchStorage.ts` に `localStorage` の読み書きと検証を実装する。
- `stores/useAttendanceStore.ts` に `punches` と `days`、および打刻のアクションを実装する。
- UI は未整備でよい。ボタン 1 つと、ストアの内容をそのまま出力する `<pre>` があれば足りる。

**習得対象:** `defineStore`、state/getters/actions、`computed` による導出、外部データの検証。
**完了条件:** ボタンを押すとストアが更新され、リロードしても記録が残る。

## フェーズ 3 — 打刻パネル

**目標:** 実際に打刻できる UI を作ること。

- `PunchPanel.vue` に 4 つのボタンと勤務状態の表示を実装する。
- `allowedPunchTypes` の結果でボタンの活性を制御する。
- 実働時間と休憩時間を表示する。

**習得対象:** `computed`、条件付きの属性バインディング、`v-for` によるボタンの生成、ストアの参照。
**完了条件:** 4 種類の打刻ができ、打てない打刻が無効になる。

## フェーズ 4 — 記録の一覧と修正

**目標:** 過去の記録を表示し、修正できるようにすること。

- `DayCard.vue` で日付ごとの集計と打刻一覧を表示する。
- `PunchRow.vue` は打刻 1 件を表示し、操作の意図を emit する。
- `PunchForm.vue` で時刻と種別を入力し、追加と修正の両方に用いる。
- 検出した不整合（打刻漏れ）を警告として表示する。

**習得対象:** props と `defineProps`、`emit` と `defineEmits`、`v-model`、`v-if`/`v-else`、コンポーネントの合成。
**完了条件:** 打刻の修正・追加・削除ができ、集計が即座に追随する。

## フェーズ 5 — 現在時刻と経過時間

**目標:** 実時間の表示を追加し、ライフサイクルとクリーンアップを習得すること。

- `useAutoRefresh` で `onMounted` に開始し `onUnmounted` で破棄する定期実行を実装する。
- `useNow` をその上に構築し、現在時刻を返すコンポーザブルとする。
- 勤務中・休憩中の経過時間を表示する。

**習得対象:** `onMounted`/`onUnmounted`、コンポーザブル、コンポーザブルの合成、タイマーのクリーンアップ。
**完了条件:** 時計が動き、勤務中の経過時間が増えていく。追加・削除時にコンソールへ警告が出力されない。

## フェーズ 6 — ストレッチ課題（任意に選択する）

- **月次の集計** — 月ごとの実働時間の合計と勤務日数。
- **勤務時間のグラフ** — 日ごとの実働時間の推移。`chart.js` と `vue-chartjs` を導入する。
- **CSV の書き出し** — 記録をファイルとして保存する。
- **所定労働時間との差分** — 過不足の表示。
- **ダークモード** — テーマの切り替え。
- **テスト** — `services/attendance.ts` と `services/time.ts` に対する Vitest の導入。集計処理は純粋関数
  であるため、テストの題材として適している。

---

## 進め方

1. 対象フェーズに関係するドキュメント 02〜03 の該当箇所を読む。
2. 動作する最小限の実装を行う。
3. 意図的に動作を壊してみる。たとえば集計結果を `ref` に保存してから打刻を修正し、表示が古いまま
   になることを確認する。導出値を保存しない理由が実感できる。
4. フェーズごとにコミットする。小さなコミットの蓄積が、そのまま学習の記録となる。
